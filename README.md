# CadQuery First Steps — by Lilian

Construction engineer with 20+ years of experience (wooden, steel, concrete stairs) — now learning to automate CAD with Python.

## Project: Parametric Step Generator
- Generates a single stair step with customizable dimensions
- Fully parametric: width, depth, height
- Filleted edges — just like real staircases I’ve designed

## Why?
I spent decades designing real staircases. Now I’m learning to generate them with code — to help train AI for CAD automation.

## Tools
- CadQuery 2.5
- CQ-Editor (installed via pip)
- Python 3.12

## Next Steps
- Generate full staircases (straight, L-shaped)
- Add stringers, railings, materials
- Export to STEP/STL for AI training datasets
